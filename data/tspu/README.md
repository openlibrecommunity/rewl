# ТСПУ: внутренняя документация

Утёкшая техническая документация АСБИ (Автоматизированная система обеспечения
безопасности интернета) и оборудования ТСПУ производства RDP.ru.

## Структура

- `chapters/` — 24 главы технического описания системы (markdown)
- `equipment/` — датащиты и руководства оборудования RDP.ru (PDF + распознанный текст)

Каждый PDF сопровождается `.txt` версией для поиска и индексации.
